# Phase 1: Benchmark And Map Shell

## Goal
Document the current map shell and compare it against Google Maps layout behavior.

## Tasks
1. Capture desktop and mobile screenshots of current map states.
2. Inventory every major surface:
   - left device panel
   - floating controls
   - selected-device overlay
   - geofence workspace
   - allowed-zone panel
   - mobile drawer
3. Record which surfaces can coexist today.
4. Benchmark against Google Maps in two states:
   - no focused object
   - focused object
5. Produce a shell map showing:
   - primary canvas
   - primary panel
   - contextual overlays
   - edit surfaces

## Output
- shell inventory
- benchmark notes
- current-state screenshot set
- conflict list of overlapping surfaces

## Acceptance
- every map surface is listed with owner component and viewport behavior
- at least one desktop and one mobile shell diagram exist
