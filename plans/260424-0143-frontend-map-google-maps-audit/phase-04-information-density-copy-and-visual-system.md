# Phase 4: Information Density Copy And Visual System

## Goal
Reduce cognitive load and keep the map readable.

## Tasks
1. Audit selected-device overlay content into three levels:
   - immediate decision info
   - quick secondary info
   - deep details that belong elsewhere
2. Reduce repeated labels and verbose copy.
3. Set typography and spacing hierarchy for map surfaces.
4. Define compact action patterns:
   - primary quick actions
   - secondary hidden actions
5. Define when badges, chips, and metrics are justified.

## Output
- information hierarchy for each surface
- compact copy rules
- map-specific spacing and density rules
- selected-device overlay content contract

## Acceptance
- overlay content can be scanned in 1-2 seconds
- advanced options are collapsed by default
- no surface tries to be both summary and detail page
