# Phase 7: Rollout Verification And Audit Closure

## Goal
Execute safely and verify both functionality and visual quality.

## Tasks
1. Implement in small passes aligned with phases 2-6.
2. After each pass, verify:
   - local browser behavior
   - desktop screenshots
   - mobile screenshots
3. Run a UI audit checklist against the updated code.
4. Deploy to UAT only after local and browser checks pass.
5. Re-audit UAT with screenshots and issue notes.

## Output
- rollout checklist
- pass/fail verification matrix
- screenshot pack for before/after
- residual issue list

## Acceptance
- UAT behavior matches the approved mode matrix
- screenshot review shows improved map readability
- no major regression remains open
