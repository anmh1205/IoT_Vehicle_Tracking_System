# 02. Hardware (Phần cứng)

Folder này chứa các phần liên quan đến thiết kế phần cứng và quản lý năng lượng.

## Nội dung

- **part-03-phan-cung.md**: Lựa chọn thành phần phần cứng (MCU, IMU, modem, pin, mạch bảo vệ)
- **part-04-quan-ly-nang-luong.md**: Chiến lược quản lý năng lượng (3 chế độ hoạt động, LVD, pin backup)
- **part-06-tinh-toan-nang-luong.md**: Tính toán thời gian hoạt động từ pin và ắc quy

## Workflow

1. Đọc `part-03-...` để chọn components
2. Thiết kế chiến lược năng lượng trong `part-04-...`
3. Tính toán và validate trong `part-06-...`
