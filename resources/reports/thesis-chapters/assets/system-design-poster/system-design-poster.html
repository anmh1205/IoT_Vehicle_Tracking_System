3. Kiến trúc hệ thống từ thiết bị đến dashboard

1. Thiết bị trên xe

  • ESP32-S3
  • SIM7600CE-T (4G/LTE + GNSS)
  • OBD-II BLE (Vgate iCar Pro)
  • LIS3DH (cảm biến gia tốc)
  • MicroSD (lưu đệm dữ liệu)
  • Pin 18650
  • Nguồn 12-24 VDC

2. Firmware thiết bị

  • Đọc GNSS / OBD-II / IMU
  • Chế độ chạy - đỗ - cảnh báo
  • Ngủ sâu, tiết kiệm năng lượng
  • Lưu đệm dữ liệu vào SD
  • Gửi bù khi có kết nối lại
  • Cập nhật firmware từ xa (OTA)

3. Truyền dữ liệu

  • MQTT 3.1.1 qua 4G/LTE
  • TLS
  • rawdata / telemetry
  • status / heartbeat
  • events / alerts
  • firmware / OTA
  • commands
